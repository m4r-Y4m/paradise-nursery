
# Paradise Nursery

## Project Description
Paradise Nursery is an online plant shopping application. Users can browse different houseplants, view their prices, and add plants to their shopping cart.

## Features
- Browse different plant categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase and decrease product quantities.
- Remove plants from the cart.
- Calculate the total shopping amount.

## Technologies Used
- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Router

Paradise Nursery Shopping Application
